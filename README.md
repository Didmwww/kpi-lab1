# 🎮 Ігровий блог & Web-лабораторні

**Виконав:** студент ФІОТ, Осадчий Дмитро

Цей проект являє собою статичний веб-сайт, присвячений відеоіграм, зокрема детальним оглядам таких ігор як Terraria та Ostriv. Окрім інформаційної складової, сторінки проекту слугують практичним майданчиком для реалізації лабораторних робіт (№6, №7, №8) з вивчення можливостей сучасного JavaScript.

## 🚀 Основний функціонал та реалізовані технології

* **HTML5:** Семантична розмітка контенту, використання різноманітних списків (`ul`, `ol`, `dl`) та побудова структурованих таблиць.
* **CSS3:** Адаптивне оформлення за допомогою Flexbox та float-елементів. Використання псевдокласів (`:hover`, `:first-child`) та псевдоелементів (`::before`, `::after`) для покращення візуального досвіду. Реалізовано фіксоване навігаційне меню (`position: sticky`).
* **Взаємодія з BOM:** Інтерактивні елементи для спілкування з користувачем через `alert`, `prompt` та `confirm`, а також керування перенаправленнями сторінок.
* **Маніпуляції з DOM:** Динамічна зміна контенту (методи `prepend`, `append`, `after`, `replaceWith`, `remove`), зміна стилів "на льоту" та створення нових елементів через JavaScript.
* **Обробка подій (Events):** * Призначення обробників через атрибути, властивості DOM та метод `addEventListener`. 
  * Використання об'єктів як обробників (`handleEvent`).
  * Патерн "Делегування подій" для оптимізації роботи навігаційних меню та списків.
* **Розширені події миші:** Відстеження `mouseover` / `mouseout` з використанням `relatedTarget`, а також повноцінна власна реалізація механіки **Drag-and-Drop** для інтерактивних блоків.

## 📂 Структура проекту

* `index.html` — Головна сторінка ігрового щоденника з інтерактивними діалогами та демонстрацією делегування подій.
* `terraria.html` — Огляд гри Terraria, що містить кнопки для динамічної модифікації DOM-дерева.
* `ostriv.html` — Сторінка про українську містобудівну стратегію з галереєю зображень та таблицею ресурсів.
* `about.html` — Інформація про автора, експериментальна зона для тестування подій миші та інтерактивний Drag-and-Drop елемент.
* `style.css` — Єдиний файл стилів, що відповідає за візуальне оформлення всього сайту.
* `script.js` — Основний JavaScript-файл, що містить логіку для всіх лабораторних завдань.

## ⚙️ Як запустити

Оскільки це повністю клієнтський (frontend) проект без використання бекенду чи збирачів, для його перегляду не потрібне встановлення додаткових інструментів:

1. Склонуйте репозиторій на свій комп'ютер.
2. Відкрийте файл `index.html` у будь-якому сучасному веб-браузері.
3. Дозвольте виконання скриптів, якщо браузер запитає дозвіл на показ спливаючих вікон (для коректної роботи BOM-елементів).
